Overgrown VR (Google Cardboard) is a cooperative plant growing simulator where players run a greenhouse together.

* Move around using the joystick.
* Trigger / OK to interact.
* X to pick up / drop items.
* B to open Pause Menu
* Pressing trigger teleports on the ground using a raycast.
* Looking at interactable objects will be outlined.

---
NPCs will look at the Display area and ask you to grow a new flower for them.

To grow a flower:
* Grab a seed bag and flower pot from the back storage area.
* Plant the seed using the plant beds on the left side greenhouse.
* Grab and fill a watering can using the well from the right side greenhouse.
* If the customer wants a specific color, dye water using the dye sacks.
* Water the flower by interacting with the plant bed (Using magic it grows super fast)!
* While holding the pot, interact with a fully grown flower to put it in.

---

Our game is cooperative where players can help split up the tasks to deliver the plant faster.
For example, one player grabs seeds while the other gets pots to prevent backtracking.

To run on mobile devices, just start the game and you will be put in the lobbyScene.
One player can host the lobby, give the code to a friend, Then the 2nd player types in the code using the virtual number pad to join the lobby.
